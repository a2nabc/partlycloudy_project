# Partly Cloudy fMRI Encoding Project

This project investigates whether features extracted from a pretrained
deep neural network can explain fMRI responses during movie viewing.

## Planned stages

1. Reproduce the standard hand-coded event analysis (Jaakko's Ms Thesis)
2. Extract visual features from the movie.
3. Align stimulus features with the fMRI time series.
4. Fit and evaluate fMRI encoding models.
